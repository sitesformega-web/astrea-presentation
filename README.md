# ASTREA™ Presentation

Presentación web comercial de ASTREA™ orientada a clientes,
potenciales socios e inversores.

## Principio

La presentación se construye mediante componentes y capas visuales
independientes.

Cada elemento puede poseer su propia composición, comportamiento
e interacción.

## Stack inicial

- HTML
- CSS
- JavaScript

## Arquitectura visual

La presentación mantiene una arquitectura propia.

No modifica ni forma parte del Design System utilizado por los módulos
administrativos de ASTREA™.
